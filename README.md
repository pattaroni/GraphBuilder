# GraphBuilder

Курсовий проєкт з дисципліни «Технології програмування».
Тема: «Програмна реалізація модуля «Побудова графіків функцій»».

Програма будує графіки математичних функцій. Написана на C# з інтерфейсом Avalonia.

## Як запустити

Потрібен .NET SDK 10.

    dotnet run --project GraphBuilder

Запуск тестів:

    dotnet test

## Що вміє

- будує графіки десяти функцій: лінійної, квадратичної, кубічної, синуса, косинуса, тангенса, гіперболи, показникової, логарифмічної та кореня;
- показує кілька графіків одночасно, кожен своїм кольором;
- малює сітку та осі з числами, перемальовує полотно при зміні розміру вікна;
- перериває лінію на асимптотах і там, де функція не визначена;
- показує координати курсора в рядку стану;
- перевіряє введені дані і показує повідомлення українською.

## Гарячі клавіші

- Enter: побудувати графік
- Delete: видалити вибраний графік
- F1: довідка
- Esc: закрити вікно повідомлення
